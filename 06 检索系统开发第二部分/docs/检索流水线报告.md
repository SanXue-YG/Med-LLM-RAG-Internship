## 1. 概述

本阶段在 05 查询增强与 04 向量索引基础上，实现 **多路检索 → 融合 → 多准则重排序**，并封装为可复用的端到端流水线，供后续 LangChain RAG 直接调用。

### 1.1 处理流水线

```
用户 query
    ↓ 05 MedicalQueryEnhancer → EnhancedQuery
    ↓ 向量路（Chroma + BGE）+ 关键词路（BM25）
    ↓ 融合（simple / rrf / weighted，默认 rrf）
    ↓ BGE reranker + slim 回查 recency / authority
最终 Top-K 候选（含分项得分与解释字段）
```

## 4. 样本库端到端验证（`pipeline_eval.json`，2026-06-17）

> **范围限定**：本节全部结果来自 **样本库**（1,267 chunks，`pmc_oa_comm_sample`），仅证明流水线可运行；**不代表** 全量 610 万 chunks 下的检索质量。RAG 上线前须按 §1.2 切换 `mode="full"` 重新评测。

**环境**：样本 chunks 1,267 条；Chroma `pmc_oa_comm_sample`；slim 本地副本；`top_k_vector/keyword/fused=10`，`top_k_final=5`。

### 4.1 时延（5 条 query，含 reranker）

| 指标 | 值 | 说明 |
|------|-----|------|
| total p50 | **86 ms** | 模型已缓存后的典型单条时延 |
| total p95 | **3919 ms** | 首条 query 含 reranker 冷启动加载 |

首条 query 的 `rerank_ms≈2683ms` 主要为模型加载；后续 4 条均在 **82–103 ms** 量级。

### 4.2 验证 query Top-1（pipeline 最终输出）

| Query | Top-1 chunk | 简要结论 |
|-------|-------------|----------|
| `metformin cardiovascular effects` | `PMC520826` | 同型半胱氨酸与**心血管**风险；BM25 路候选经 rerank 顶位（无 metformin 字面，样本库局限） |
| `papers on malaria after 2015` | `PMC523837` | 疟疾相关；`year_hint=2015` 已传入，样本库无 2015+ 篇，recency 难体现 |
| `MI treatment guideline` | `PMC522817` | 临床指南类文献，与 C6/C8 一致 |
| `circadian rhythm sliding window chunks` | `PMC524494_chunk1` | strategy 过滤下命中 sliding_window chunk |
| `warfarin atrial fibrillation elderly` | `PMC509245` | 房颤抗凝相关 RCT，双路术语召回正常 |

### 4.3 与分步 notebook（C8）的差异说明

- C8 对 metformin 重排顶位为 `PMC521687`（冠脉搭桥 stress）；C10/C11 pipeline 顶位为 `PMC520826`（心血管 biomarker 日节律）。
- 原因：pipeline 融合池 `top_k_fused=10`（C6 部分步骤为 5），rerank 候选集合更大，cross-encoder 对「cardiovascular」语义有不同取舍。
- **结论**：端到端链路行为符合设计；排序对候选池大小敏感，全量库联调时可固定 `top_k_fused=30` 再评估。

## 5. 全量盘联调（C12，`pipeline_eval_full.json`，2026-06-18）

> **范围**：Chroma **真实全库**（6,107,296 条，`pmc_oa_comm_full`）；BM25 为 E: JSONL **前 100,000 条探测索引**（31.5s 构建），非完整 610 万 BM25。3 条 query 端到端含 rerank。

### 5.1 时延与资源

| 指标 | 值 | 说明 |
|------|-----|------|
| BM25 探测建索引 | **31.5 s** | 100,000 chunks |
| total p50 / p95 | **34.1 s / 35.2 s** | 3 条 query |
| `retrieve_ms` | 140–1704 ms | 首条含 embedder 预热；向量全库查询可接受 |
| `rerank_ms` | **≈33–34 s/条** | **当前瓶颈**；生产需控制 `top_k_fused` 或 GPU batch |

### 5.2 样本库 vs 全量 Top-1 对比

| Query | 样本 Top-1 | 全量 Top-1 | 变化 |
|-------|-----------|-----------|------|
| metformin cardiovascular effects | `PMC520826`（心血管 biomarker，无 metformin） | **`PMC2566605_chunk2`**（metformin T1DM RCT，`rel=0.93`） | ✅ 质量显著提升 |
| MI treatment guideline | `PMC522817`（指南） | `PMC2637970`（心梗修复） | MI 主题更贴，但非 guideline |
| papers on malaria after 2015 | `PMC523837`（疟疾，2004） | `PMC12822982`（`pub_year=2026`，非疟疾） | ⚠️ recency 抬升误匹配 |

**3/3 query 的 Top-1 与样本库不一致**——印证样本库（1,267 条）不能代表全量检索结果。

### 5.3 结论与 RAG 生产建议

1. **全量 Chroma 接入成功**；药名类 query（metformin）在全量下召回明显改善。
2. **BM25 全库**仍需离线建索引（notebook 内仅 10 万条探测）；生产须用完整 `oa_comm_chunks.jsonl`。
3. **时效 query**（malaria after 2015）在全量下出现 recency 主导误排——建议提高 relevance 权重或设 `year_hint` 时过滤 `pub_year < hint`。
4. **时延**：rerank 为瓶颈；RAG 默认 `mode="full"` 时建议 `top_k_fused=30`、缓存 BM25 索引、复用已加载 reranker。
