## 1. 概述：本阶段在 RAG 里做什么

11 解决「别人怎么点餐（`/qa`）」；**12 解决「桌号怎么管、厨房仪表盘、菜单册怎么查」**——会话 CRUD、运营统计、篇级文档目录，全部挂在同一 FastAPI 进程，并与 `/qa` **共用** `SessionStore` / `QACallLogger`。

| 上游（11） | 本阶段新增（12） |
|------------|------------------|
| `POST /qa` · `MemorySessionStore` · JSONL | `POST/GET/DELETE /sessions`（完整 turns） |
| `/health` · `/ready` | `/stats/qa` · `/stats/index` · `/stats/health` |
| — | `/documents` 分页 · `/documents/{pmcid}` |
| sample/full 检索资产 | `Dataset/documents/{sample,full}` 篇级 sqlite |

```text
Client
  ├─ /sessions  → 同一 SessionStore（与 /qa 不分裂）
  ├─ /qa        → RagService → 10 ConstrainedPipeline（sample|full）
  ├─ /stats/*   → qa_calls.jsonl + Chroma/docs probe + 组件探活
  └─ /documents → documents_{sample|full}.sqlite（doc_id = pmcid）
```

## 3. API 一览（运营层）

> 机器可读契约：服务启动后 [`/docs`](http://127.0.0.1:8000/docs)。日常默认 **sample**；full 需进程级环境变量（见部署说明 §9）。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/sessions` | 创建空会话 |
| GET | `/api/v1/sessions/{id}` | 完整 turns；缺失 **3002** |
| DELETE | `/api/v1/sessions/{id}` | 删除；再 GET → **3002** |
| GET | `/api/v1/stats/qa` | JSONL 聚合 |
| GET | `/api/v1/stats/index` | chunk / document / 体积 |
| GET | `/api/v1/stats/health` | 组件状态 |
| GET | `/api/v1/documents` | PageModel + `q` |
| GET | `/api/v1/documents/{doc_id}` | `doc_id=pmcid`；缺失 **3001** |
| POST | `/api/v1/qa` · `/qa/stream` | 经 `bridge11` 挂载（11） |
