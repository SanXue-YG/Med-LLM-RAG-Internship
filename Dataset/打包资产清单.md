## 1. 运行时（问答服务建议挂载）

| 资产 | 路径 | 作用 | 缺了会怎样 |
|------|------|------|------------|
| 全量 Chroma | `chroma/chroma_db_full/` | 向量检索 | `/qa` 语义路不可用 |
| 全量 BM25 | `bm25/bm25_full/` | 关键词检索 | 多路检索缺 BM25 |
| **全库文档索引** | `documents/full/documents_full.sqlite` | `/documents` + **替代 slim 回查** year/journal | 目录 API 空；重排 recency/authority 退化 |
| （配置） | env / `.env` | `MED_RAG_RETRIEVAL_MODE=full` 等 | — |

体积量级（本机实测口径）：Chroma ~66–71 GB；BM25 ~15 GB；**文档 full sqlite ≈ 11.5 GB**（4,557,627 篇，含 abstract；2026-07-27）。

**模型（通常不进 Dataset）**：Ollama `deepseek-r1:7b`；HF `bge-small` / `bge-reranker` 缓存。

## 2. 重建原料（可不进运行镜像，外置备份即可）

| 资产 | 路径 | 用途 |
|------|------|------|
| slim | `processed/oa_comm_slim.jsonl` | 重建 documents sqlite；历史 06 直接回查 |
| chunks | `processed/oa_comm_chunks.jsonl` | 重建 Chroma / BM25 |
| 样本 chunks | `processed/chunks_sample.jsonl` | 开发/重建样本侧 |
| 样本文档索引 | `documents/sample/documents_sample.sqlite` | 开发契约 |

→ **不必**为了「回查 + 检索」在运行包里同时塞 slim **和** chunks；运行靠 **Chroma + BM25 + documents.sqlite**。
