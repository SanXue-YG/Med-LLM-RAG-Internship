# Med-RAG 流程图

> **本文职责**：问答与上传的数据流简图。路径对照见 [`数据存储与导入参考.md`](数据存储与导入参考.md)。

## 总览

```text
┌────────────┐     HTTP      ┌──────────────────────────────┐
│  React UI  │ ────────────► │  FastAPI (backend/app)       │
│  Vite:5173 │ ◄──────────── │  /qa /sessions /ingest ...   │
└────────────┘               └──────────────┬───────────────┘
                                            │
                     ┌──────────────────────┼──────────────────────┐
                     ▼                      ▼                      ▼
              data/chat/            ConstrainedGeneration    data/raw_uploads
           (会话 JSON)              Pipeline.from_mode(mode)  → ingest（固定 sample）
                                            │
              mode=sample ──► chroma_db + chunks_sample (+ documents/sample)
              mode=full   ──► chroma_db_full + bm25_full (+ documents/full)
                                            │
                                            └─► Ollama
```

## 模式角色

| 模式 | 产品角色 |
|------|----------|
| sample | 接近用户本机使用：可空启动、回形针可增量更新 |
| full | 预建数据集迁入后问答；一期 Demo **不能**上传更新全库 |

## 语料更新（回形针）— 始终 sample

与 `MED_RAG_RETRIEVAL_MODE` **无关**：

```text
上传 XML/JSONL
  → data/raw_uploads/
  → parse / chunk
  → append chunks_sample.jsonl
  → Chroma collection.add (pmc_oa_comm_sample @ chroma/chroma_db)
  → documents_sample.sqlite upsert
  → reset RagService singleton
```

**注意**：服务若已切 full，上述写入**不会**进入 full 检索结果；验证上传请保持或切回 sample。
