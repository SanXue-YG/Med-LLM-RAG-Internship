## 1. 目标与范围

本阶段目标是在 05/06/07 的基础上完成可运行的生成链路：

- 接入本地 Ollama（`deepseek-r1:7b`）
- 实现 `MedicalGenerationPipeline.run(query)` 端到端流程
- 输出可追溯结果结构（答案、来源、中间产物、指标）
- 完成 notebook 贯穿式演示（C0–C7）与批量评测快照

不包含：LangChain 封装、生产部署、UI 流式交互。

## 2. 关键实现

### 2.1 LLM 调用层

- 文件：`src/llm_generator.py`
- 主要能力：
  - `health_check()` / `ping()`
  - `generate()`（system+user，支持 `temperature`、`max_tokens`）
  - `generate_json()`（JSON 约束 + 解析）
  - `generate_batch()`

实现要点：

- 默认 `think=False`（避免 deepseek-r1 thinking 链吞掉 token 预算）
- `max_tokens` 建议不少于 512

### 2.2 JSON 解析与降级

- 文件：`src/json_utils.py`
- 主要能力：
  - 围栏 JSON 提取
  - 残缺 JSON 修复（尾逗号、缺括号、引号）
  - 证据评估 schema 归一化
  - 评估失败时降级：不筛选 chunk，主流程继续

### 2.3 生成主流程

- 文件：`src/generation_pipeline.py`
- 流程：
  1) retrieval + assemble  
  2) evidence evaluator（可选）  
  3) draft generator  
  4) critical reviewer（可选）  
  5) final assembler  
  6) postprocess

输出字段（核心）：

- `answer`
- `sources`

- `generation_metrics`（`total_time_seconds` / `stage_times` / `stage_success`）
- `intermediate_results`（evidence/draft/review）

### 2.4 后处理与来源对齐

- 文件：`src/postprocess.py`
- 主要能力：
  - `format_sources()`：标准化来源列表
  - `postprocess_answer()`：引用标记、Sources 区块、免责声明
  - `MEDICAL_DISCLAIMER` 常量统一
